# Stitch 프롬프트 — 직장인 맛집지도

[Stitch](https://stitch.withgoogle.com)에 붙여넣어 UI/UX 시안을 받기 위한 프롬프트.
아래 "메인 프롬프트"를 먼저 넣고, 화면별 프롬프트를 이어서 하나씩 요청하면 된다.

> **중요**: 이 앱은 **사진 데이터가 존재하지 않는다**(출처 표기 불가로 수집 금지). 스티치는 기본적으로
> 음식 사진 카드를 넣으려 하므로, 프롬프트의 금지 항목을 절대 빼지 말 것. 사진이 들어간 시안은
> 구현할 수 없다.

---

## 1. 메인 프롬프트 (가장 먼저 입력)

```
한국의 직장인용 맛집 지도 웹앱을 디자인해줘. 이름은 "직장인 맛집지도".

무엇을 하는 앱인가:
서울 창동 씨드큐브 오피스 빌딩에서 반경 5km 안에 있는, 회사 모바일 식권(비플페이)으로
결제 가능한 음식점·카페·편의점 6,122곳을 지도에 표시한다. 점심 시간에 "오늘 뭐 먹지"를
30초 안에 해결하는 것이 목적이다.

사용자:
30~40대 직장인. 점심시간에 서서 한 손으로 폰을 쓴다. 예쁜 걸 감상할 시간이 없고,
"가까운가 / 뭘 파는가 / 얼마인가 / 줄 서나"만 빠르게 알고 싶어 한다.

핵심 원칙:
- 지도가 주인공이다. 화면의 대부분을 지도가 차지하고, 나머지 UI는 지도를 가리지 않는다.
- 모바일 우선. 기준 화면 폭 375px에서 가로 스크롤이 절대 없어야 한다.
- 한 손 조작. 모든 터치 대상은 최소 44x44px.
- 정보 밀도는 높되 시각적 소음은 낮게. 장식보다 가독성.

절대 금지 (매우 중요):
- 음식 사진, 매장 사진, 사용자 업로드 사진, 스톡 이미지 등 어떤 사진도 넣지 말 것.
  이 앱은 사진 데이터를 보유하지 않으며 앞으로도 수집하지 않는다.
  사진 자리 표시자(placeholder), 이미지 카드, 갤러리, 썸네일 모두 금지.
- 별점 항목을 임의로 늘리지 말 것. 평가 축은 정확히 2개("맛", "점심 웨이팅")뿐이다.
- 예약, 주문, 배달, 쿠폰, 포인트, 광고 배너 같은 없는 기능을 그리지 말 것.

정보는 오직 텍스트로 전달한다: 가게 이름, 업종, 거리(km), 주소, 전화번호,
메뉴명과 가격(최대 5개), 별점 2종, 100자 이내 한 줄 리뷰.

UI 문구는 모두 한국어.
```

## 2. 화면 1 — 지도 메인

```
화면 1: 지도 메인 (모바일 375x812)

위에서 아래로:
1) 상단 바 (높이 최소 44px)
   - 왼쪽: 앱 이름 "직장인 맛집지도"
   - 오른쪽: 로그인 전에는 "구글 로그인" 버튼, 로그인 후에는 "홍길동님"과 "로그아웃"

2) 필터 바 (상단 바 바로 아래, 가로 스크롤 가능)
   - 가게 이름 검색 입력창 (placeholder: "가게 이름 검색")
   - 업종 칩 (선택 시 채워진 상태): 전체 · 한식 · 중식 · 일식 · 양식 · 카페·빵 ·
     치킨 · 피자·버거 · 분식 · 술집 · 편의점
   - 반경 슬라이더: "반경 2.5km" 형태로 현재 값 표시, 0.5~5km
   - 오른쪽 끝에 결과 수 "1,284곳"

3) 지도 (남은 공간 전부)
   - 중심에 사무실 위치 핀 하나 (다른 핀과 구분되는 형태)
   - 반경을 나타내는 반투명 원
   - 가게 핀 다수, 가까이 붙은 핀은 숫자가 적힌 클러스터로 묶임

4) 지도 위 왼쪽 아래 구석에 아주 작은 저작자 표시 한 줄
   "만든 이 노에마 · spoug02@gmail.com" (지도 조작을 방해하지 않는 반투명 배경)

진입 직후 상단에 잠깐 나타났다 사라지는 알림 바도 함께 보여줘:
노란 배경 + 검은 글씨, 왼쪽에 경고 아이콘, 문구는
"편의점은 회사 식권 정책에 따라 결제가 제한될 수 있어요. 사내 규정을 확인해주세요."
오른쪽에 닫기(x) 버튼.
```

## 3. 화면 2 — 가게 상세 (모바일: 하단 시트)

```
화면 2: 가게 상세 — 모바일에서는 아래에서 올라오는 바텀시트 (화면 높이의 약 75%)

시트 맨 위에 끌어내리는 손잡이(가로 짧은 막대)와 오른쪽 위 닫기 버튼.

내용 순서:
1) 가게 이름 (크게, 굵게) — 예: "순대실록 창동씨드큐브점"
   그 아래 한 줄로 "한식 · 0.04km"
2) 주소 "서울 도봉구 마들로13길 61", 전화번호 "02-6077-8980"
3) "카카오맵에서 보기 ↗" 링크
4) 카카오톡 공유 버튼 — 카카오 노란색 배경에 검은 글씨, 가로 전체 폭, 높이 44px 이상,
   문구 "카카오톡으로 공유"
5) "메뉴" 섹션 — 사진 없이 목록만.
   왼쪽에 메뉴명, 오른쪽 끝에 가격을 오른쪽 정렬로 붙여 시선이 가격 열에서 정렬되게.
   예: "얼큰 순대국 … 15,000원" / "모둠 순대 … 16,000원" (최대 5줄)
6) "만든 이 블로그 후기" 카드 — 다른 요소와 확실히 구분되는 옅은 색 카드.
   작은 라벨 "✍️ 만든 이 블로그 후기" 아래 글 제목 한 줄, 외부 링크임을 표시.
   (광고가 아니라 제작자 본인 글임이 드러나야 한다)
7) "리뷰" 섹션 (아래 화면 3 참조)

편의점을 선택한 경우의 변형도 함께 보여줘: "메뉴" 섹션이 통째로 사라진 모습.
(편의점은 메뉴 개념이 없다)
```

## 4. 화면 3 — 리뷰 (상세 시트 하단부)

```
화면 3: 리뷰 섹션 — 가게 상세 시트의 아래쪽. 세 가지 상태를 각각 보여줘.

공통 헤더: "리뷰 (12)" 옆에 요약 "맛 ★4.2 · 점심 웨이팅 ★2.1"

상태 A — 비로그인:
  작성 폼 대신 버튼 하나. "구글 로그인하고 리뷰 남기기" (높이 44px 이상)
  아래에는 다른 사람 리뷰 목록이 그대로 보인다 (읽기는 누구나 가능)

상태 B — 로그인 후 작성 폼:
  - 별점 두 줄. 왼쪽에 라벨, 오른쪽에 별 5개.
    첫 줄 라벨 "맛", 둘째 줄 라벨 "점심 웨이팅"
    별 하나하나가 44x44px 터치 영역
  - 한 줄 입력창, placeholder: "100자 이내로 짧게(사진은 나중에, 우리는 직장인이라 바쁘니까)"
  - 입력창 아래 왼쪽에 글자수 카운터 "37/100", 오른쪽에 "리뷰 남기기" 버튼
  - 사진 첨부 버튼은 절대 넣지 말 것

상태 C — 리뷰 목록:
  카드마다 위쪽에 작성자 이름과 "맛 ★4 · 웨이팅 ★2", 아래에 한 줄 리뷰 본문.
  사진 없음. 카드 3개 정도.
```

## 5. 화면 4 — 데스크톱 레이아웃

```
화면 4: 같은 앱의 데스크톱 화면 (1280x800)

모바일과 정보는 같지만 배치가 다르다:
- 상단 바와 필터 바는 가로로 넉넉하게 펼쳐진다 (칩이 스크롤 없이 한 줄에 다 보인다)
- 가게 상세는 바텀시트가 아니라 화면 오른쪽에 붙는 세로 패널 (폭 약 384px, 전체 높이)
- 지도는 남은 왼쪽 영역을 채운다
- 상세 패널이 열려도 지도가 계속 조작 가능해 보이도록
```

## 6. 스타일 가이드

```
스타일 방향:

톤: 실용적이고 담백하게. 점심시간에 급하게 보는 도구다.
    트렌디한 장식, 그라데이션 남용, 큰 히어로 영역, 일러스트 금지.

색:
- 기본은 흰 배경에 진한 회색/검정 텍스트. 지도가 색을 담당하므로 UI는 물러난다.
- 강조색은 한 가지만. 파랑 계열(#2563eb 정도)을 링크와 선택된 칩에 사용.
- 카카오톡 공유 버튼만 예외로 카카오 노란색(#FEE500) + 검은 글씨.
- 주의 알림 바는 노란 배경(#FDE047)에 검은 글씨.
- "만든 이 블로그 후기" 카드는 옅은 초록 계열로 다른 요소와 구분.

타이포:
- 한국어 산세리프(Pretendard 또는 Noto Sans KR 느낌).
- 가게 이름 18px 볼드, 본문 14px, 보조 정보 12px.
- 숫자(가격, 거리, 별점)는 눈에 잘 띄게.

여백과 형태:
- 모서리는 8px 정도로 약하게 둥글게. 과한 라운드 금지.
- 그림자는 떠 있는 요소(바텀시트, 알림 바)에만 얕게.
- 구분선은 얇은 회색 한 겹.

접근성:
- 모든 터치 대상 최소 44x44px.
- 텍스트 대비 4.5:1 이상.
- 노치/홈 인디케이터 영역(safe area)을 침범하지 않도록 하단 여백 확보.
```

## 7. 추가로 받아볼 만한 화면

필요하면 아래를 이어서 요청한다.

```
- 검색 결과가 0곳일 때의 빈 상태 ("조건에 맞는 가게가 없어요. 반경을 넓혀보세요.")
- 공유 링크로 들어왔는데 그 가게가 사라진 경우의 안내
  ("공유된 가게를 찾지 못했어요. 목록이 갱신되었을 수 있어요.")
- 카카오톡 대화방에 뜨는 공유 카드 모양
  (제목 "순대실록 창동씨드큐브점 · 한식", 설명 "씨드큐브에서 0.04km · 얼큰 순대국 15,000원",
   버튼 "지도에서 보기". 사진 없음)
- 앱 로고/아이콘 시안 (지도 핀 + 숟가락·젓가락 같은 단순한 결합, 단색으로도 알아볼 수 있게)
```
